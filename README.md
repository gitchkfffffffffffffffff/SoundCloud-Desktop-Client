# 🎵 SoundCloud Desktop Client

Полнофункциональный десктоп клиент SoundCloud с поддержкой офлайн режима и темной темой.

## ✨ Особенности

- 🎧 **Полный функционал плеера** - воспроизведение, пауза, перемотка, регулировка громкости
- 🔍 **Поиск** - быстрый поиск треков, артистов и плейлистов
- 💾 **Офлайн режим** - загрузка треков для прослушивания без интернета
- ❤️ **Избранное** - сохранение понравившихся треков
- 📱 **Адаптивный дизайн** - работает на любых размерах экранов
- 🌙 **Темная тема** - приятный интерфейс для глаз
- 📊 **История прослушивания** - отслеживание прослушанных треков
- 🔐 **Локальное хранилище** - все данные сохраняются локально на компьютере

## 🚀 Быстрый старт

### Требования
- Node.js 14+ и npm/yarn
- Git

### Установка

1. **Клонировать репозиторий**
```bash
git clone <repository-url>
cd soundcloud-client
```

2. **Установить зависимости**
```bash
npm install
```

3. **Получить SoundCloud API ключи**
   - Перейти на https://soundcloud.com/you/apps
   - Зарегистрировать приложение
   - Скопировать `Client ID` и `Client Secret`

4. **Добавить API ключи**
   - Открыть `src/api/soundcloud.js`
   - Заменить `YOUR_SOUNDCLOUD_CLIENT_ID` на ваш Client ID
   - Заменить `YOUR_CLIENT_SECRET` на ваш Client Secret

5. **Запустить приложение**
```bash
npm start
```

Приложение откроется в окне Electron, а React dev server запустится на http://localhost:3000.

## 📦 Сборка

## 🎮 Использование

### Поиск треков
1. Используйте поле поиска в заголовке
2. Нажмите Enter или кнопку поиска
3. Выберите трек из результатов

### Воспроизведение
- **Play/Pause** - кнопка play в плеере
- **Следующий/Предыдущий** - стрелочные кнопки
- **Громкость** - ползунок справа
- **Прогресс** - кликните на полоску прогресса

### Офлайн режим
1. Нажмите кнопку загрузки на треке (когда онлайн)
2. Трек будет сохранен локально
3. При потере интернета вы сможете его воспроизвести
4. Загруженные треки видны в сайдбаре

### Избранное
- Кликните на сердечко рядом с треком
- Добавленные треки будут доступны в разделе "Понравившиеся"

## 🔧 Технический стек

- **Electron** - десктоп приложение
- **React 18** - UI фреймворк
- **Zustand** - управление состоянием
- **Dexie** - локальная база данных (IndexedDB)
- **Axios** - HTTP клиент
- **React Icons** - иконки

## 🔐 Безопасность

- ✅ Все данные сохраняются локально на вашем компьютере
- ✅ Токены доступа хранятся в localStorage
- ✅ Нет отправки данных на внешние серверы (кроме SoundCloud API)
- ✅ Приложение работает полностью локально

## 🐛 Решение проблем

### Приложение не запускается
```bash
npm install
npm start
```

### Проблемы с CORS
- Убедитесь, что используется правильный API endpoint
- Проверьте настройки CORS на SoundCloud стороне

### Офлайн режим не работает
- Проверьте, что браузер поддерживает IndexedDB
- Убедитесь, что есть достаточно места на диске
